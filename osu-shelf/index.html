osu-shelf

Download osu!collector collections and get them into osu!, from a desktop app or your terminal.

Every map comes from public beatmap mirrors, with a real collection.db alongside, and you never sign in to osu!. Works with osu!lazer (Torii and other lazer builds too) and osu! stable.

Latest release v0.3.0 Join the Discord

An unofficial community tool, not made, endorsed or supported by ppy or osu!Collector. A fork of uwuclxdy/osu-collect.

Install

Terminal app

Updates itself. The app and its command are both called osu-shelf, so run osu-shelf once it's installed.

Linux x64 / macOS Apple Silicon

curl -fsSL https://raw.githubusercontent.com/DesireThings/osu-shelf/main/install.sh | bash

Windows x64 (PowerShell)

iwr https://raw.githubusercontent.com/DesireThings/osu-shelf/main/install.bat -OutFile "$env:TEMP\osu-install.bat"; & "$env:TEMP\osu-install.bat"; Remove-Item "$env:TEMP\osu-install.bat"

The apps aren't signed with a paid certificate, so the first start shows a warning: on Windows, More info → Run anyway; on macOS, System Settings → Privacy & Security → Open Anyway. The desktop app doesn't update itself yet; install a new version over the old one.

Early access (0.x): the Windows and macOS installers are built and checked automatically but haven't been run on a real Windows PC or Mac yet. If one doesn't work, please open an issue.

Features

  • mirrors

    Nine mirrors with failover

    When a mirror rate-limits, its maps wait and retry while the rest keep downloading. Skip the stuck ones and fetch them later if you like.

  • find

    Find maps without a collection

    Search by name, stars, mapper, BPM and more, through the osu! API or nzbasic's community map database.

  • collection.db

    A real collection

    A verified collection.db next to the maps, so the collection itself shows up in osu!, not just the maps.

  • update

    Keep collections up to date

    Check a downloaded collection again and fetch only the new or missing maps.

  • no login

    No osu! login

    Paste a collection link and go. osu-shelf never asks for your osu! account.

  • lazer

    Everything into lazer at once

    However many collections you download, osu!lazer imports every map and collection in a single pass of its setup wizard.

~/osu-shelf> osu-shelf

Three steps

  1. Paste

    Paste one or more osucollector.com links and check the names and map counts.

  2. Pick a folder

    Choose osu!lazer or osu! stable and a download folder. Your osu! folder is found automatically when it's in the usual place.

  3. Import into osu!

    For lazer, prepare the import folder and run osu!'s setup wizard once. For stable, drag in the .osz files and merge the collection.db with Collection Manager.

FAQ

Do I need an osu! account?

Not to download collections: osu-shelf never asks for your osu! login. Only the terminal app's find, when it searches through the osu! API, needs an API app of your own, which you make on your osu! account page; see Finding maps.

Where do the maps come from?

The collection's details come from osu!Collector; the maps come from public beatmap mirrors, not from osu!'s servers. Which mirrors, and in what order, is up to you in the settings.

A download says map sets are "waiting for a free mirror". Is it stuck?

No. Every mirror that has those maps is rate-limiting, so they're retried once a mirror frees up, usually within minutes. In the desktop app you can Skip these for now and get them later with Check again.

I also use uwuclxdy's osu-collect. Can I keep both?

Yes. Since 0.3.0 the two keep separate settings: osu-shelf reads its own osu-shelf folder and copies the old osu-collect one once on first start, leaving the original's files alone. An existing ~/Downloads/osu-collect folder keeps being used for downloads, so rename it or pick another folder if you want them apart. A saved osu!lazer login is dropped from the copy, because osu-shelf no longer signs in through osu!lazer's client. The original keeps updating from its own releases.

Does osu!Collector have its own app?

Yes, the osu!Collector desktop client. Its subscription pays for the site that hosts every collection osu-shelf reads. If you use osu!Collector a lot, consider supporting it.
